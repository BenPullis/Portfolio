# Ben Pullis – Portfolio

Static personal portfolio (HTML, CSS, JavaScript). No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:
```
python3 -m http.server 8000
```

## Structure
- `index.html` – all page content and sections
- `css/main.css` – styles, light/dark theme tokens at the top
- `js/main.js` – nav, theme toggle, typing effect, counters, star background
- `js/classes.js` – list of classes taken (edit here to add/retag courses)
- `assets/` – resume PDF and headshot

## Libraries (via CDN)
Font Awesome (icons), Google Fonts (IBM Plex Sans, IBM Plex Mono).
